# Evaluation Metrics

This document describes the metrics used to evaluate the performance of the chatbot.

---

## 1. Intent Accuracy
Measures how accurately the chatbot predicts user intent.

Formula:
Correct intent predictions / Total predictions

---

## 2. Emotion Accuracy
Measures the correctness of detected user emotions.

Formula:
Correct emotion predictions / Total predictions

---

## 3. Failure Rate
Measures the proportion of conversations that end unsuccessfully.

Formula:
Number of failed conversations / Total conversations

---

## 4. Resolution Quality Score
Measures how effectively user issues are resolved.

Based on:
- Successful resolution flag
- User sentiment improvement
- Reduced repetition

---

## 5. Learning Improvement Score
Measures improvement after retraining using failure data.

Comparison:
Performance before learning vs performance after learning
