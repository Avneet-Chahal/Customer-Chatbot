# Data Schema

This document defines the data structures used in the Self-Improving AI Customer Support Chatbot.

---

## 1. Conversation Log Schema

Stores every interaction between the user and the chatbot.

Fields:
- conversation_id: Unique identifier for each conversation
- user_id: Unique identifier for the user
- timestamp: Date and time of the interaction
- user_message: Text entered by the user
- detected_intent: Predicted user intent
- detected_emotion: Predicted user emotion
- confidence_score: Confidence level of the prediction
- bot_response: Response generated by the chatbot
- resolution_status: Resolved or Unresolved

---

## 2. Failure Log Schema

Stores information about failed or unresolved conversations.

Fields:
- failure_id: Unique identifier for failure case
- conversation_id: Reference to conversation log
- failure_reason: Reason for failure (repetition, negative emotion, abandonment)
- failure_count: Number of times failure occurred
- detected_emotion: Emotion at failure time
- timestamp: Time when failure was detected

---

## 3. User Memory Schema

Stores user-specific information with time-based decay.

Fields:
- user_id: Unique identifier for the user
- past_issues: Previously reported problems
- preferences: User preferences (if any)
- last_interaction_time: Most recent interaction timestamp
- memory_priority: Importance level of stored memory
- decay_timestamp: Time when memory should be reduced or removed
